consulta.js é a página de busca. Todo elemento é criado com createElement e todo texto vindo da API entra por textContent, nunca por innerHTML: um teste garante que nenhum arquivo JavaScript do projeto usa innerHTML, eval ou document.write. As chamadas à API não enviam cookies, e uma busca nova cancela a anterior com AbortController.
