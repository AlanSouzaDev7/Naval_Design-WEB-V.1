deploy/render.yaml descreve a publicação no Render: o serviço web em Python, o comando de build e o de start com gunicorn. As variáveis sensíveis, como a senha do banco, o host do Neon e o token do GitHub, aparecem com sync: false, ou seja, o valor fica só no painel do Render e nunca no repositório. A conexão com o banco usa TLS com verificação completa do certificado.
