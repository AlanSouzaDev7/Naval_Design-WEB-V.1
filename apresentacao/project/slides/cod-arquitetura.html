Abertura da seção técnica. O site tem três camadas. No navegador, HTML, CSS e JavaScript puros, com Three.js para os navios 3D e Canvas 2D para as animações dos heros e do mergulho. No servidor, Python com Flask: o servidor em si, a API de consulta somente-leitura, a página de sugestões com painel administrativo, a proteção dos formulários e a geração de PDFs. Nos dados, PostgreSQL gerenciado pelo Neon em produção, preparado por dois scripts SQL. As sugestões do público não vão para o banco: ficam num arquivo JSON versionado no GitHub.
