Esta é a consulta de busca, em SQL do PostgreSQL. O texto do usuário entra como parâmetro (%(q)s), nunca concatenado, o que fecha a porta para SQL injection. A busca compara texto normalizado, sem acentos, e usa word_similarity da extensão pg_trgm para tolerar erros de digitação. A ordenação privilegia o nome exato, depois o prefixo, depois a similaridade.
